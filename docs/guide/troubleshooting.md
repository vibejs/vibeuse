# Troubleshooting

If a ref or getter appears frozen, check that you passed the ref or a getter rather than its current value. If an element is initially null, bind a vibe.js useTemplateRef and let the composable track its arrival.

If storage did not save a nested mutation, replace data.value or call write(). Inspect error for quota, serializer or access failures. Cross-tab synchronization is native and does not emit same-tab events.

If clipboard fails, invoke copy from a user gesture in a secure context and inspect error. If an observer is unsupported, isSupported is false; no polling fallback is installed.

If cleanup seems missing outside components, create an explicit effectScope or call stop(). A stopped controller is terminal. Avoid multiple utilities owning the same title, favicon or dark class.
