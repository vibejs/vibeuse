# Installation

Install the library alongside Vibe.js 0.1.x. Your application must already have the matching Vibe.js compiler and language tools.

```sh
pnpm add @usevibejs/use @usevibejs/ui@^0.1.0
```

The ESM package has no runtime dependencies. Vibe.js is a required peer. Imports work from the root or category subpaths: reactivity, browser, storage, elements, sensors and timers. This repository is local development work; registry availability is controlled by the release process.
